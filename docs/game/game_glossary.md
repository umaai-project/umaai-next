# 游戏通用术语表（Game Glossary）

> 与 [游戏规则（game_rules.md）](game_rules.md) / [实现细节（game_implementation.md）](game_implementation.md) 配套，**只收游戏原生术语**。列序按重要度：**中文 > 日文 > 程序 > 备注**。
> **中文**为主词条；**日文**取自现有数据，不作翻译；**程序**为本仓代码中的对应表述（trait / 字段 / 枚举，含剧本 crate 的旧实现命名），无对应则留空。
> 数据来源：`mee-umasim/data`（通用 + onsen / ramen / mujinto memo）、本项目 `ramen_memo.md`、`cardDB.json`、`text_data_dict.json`、`scenario_ramen.json`。
> 无人岛剧本文档名为 `mujinto`，游戏数据库内为 **pioneer（开拓先驱）**，此后统一以 **pioneer / 无人岛** 为准。
> 与游戏概念无关、仅属项目架构的标识符见 [项目术语表（glossary.md）](glossary.md)。

## 育成流程

| 中文   | 日文      | 程序                          | 备注                         |
| ---- | ------- | --------------------------- | -------------------------- |
| 回合   | ターン     | `turn`                      | 通常剧本包括 78 回合；一部分剧本回合数更少需单独记录；游戏中显示回合从1开始，本文档和AI端从0开始，需要注意转换 |
| 训练   | トレーニング  | `Train`                     | 基础训练包含：速 / 耐 / 力 / 根 / 智 五个训练位，一部分剧本有特殊训练 |
| 休息   | お休み     | `Sleep`                     | 消耗回合，随机恢复体力（见机制文档）；夏合宿期间固定为回体+加心情  |
| 外出   | お出かけ    | `FriendOuting` / `NormalOuting` | 消耗回合，触发随机外出事件。如果友人已解锁，可以选择`友人外出` |
| 比赛   | レース     | `Race`                      | 生涯比赛 / 自选比赛 / 非生涯比赛   |
| 固定路线   |   |                      | 一部分剧本不进行生涯和自选比赛，改为固定赛程 |
| 事件   | イベント    | `event`                 | 基础词组；衍生如连续事件、事件选项                |
| 夏合宿  | 夏合宿     | `is_xiahesu`                | turn 36–39 / 60–63，强化训练/休息，不可出行 |
| 新年   | 正月      |                     | turn 24 / 48 固定发生的新年事件，固定路线的剧本不发生 |
| 粉丝数  | ファン数    |                     | 育成目标 / 事件条件；模拟时不考虑 |
| 事件发生率 | サポカイベント率 | `event_probs`             | 随机事件四分类权重：支援卡 0.35 / 马娘 0.25 / 掉心情 0.10 / 无事 0.30；估算值，支援卡发生率可能随剧本改变 |
| 剧本内置资源（泛称） | — | `scenario_pt` 等 | 各剧本内部资源 → 档位加成（パフォーマンス / メカEN / サポーターPt / 適性Pt / 発展Pt / 期待度） |
| 育成结束 | 育成終了後   | 结束事件链（`ending` 等） | 育成结束事件应统一在 turn 77 结束后（AfterTrain 或更晚）判定 |
