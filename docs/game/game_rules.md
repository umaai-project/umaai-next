> 剧本专属机制（拉面做面/吃面/地区、温泉挖掘等）见各剧本资料；游戏原生术语见 [游戏通用术语表（game_glossary.md）](game_glossary.md)。

## 0. 游戏目标

- 赛马娘游戏的核心玩法是育成和对战，本项目仅讨论育成。育成可能有不同的次要目标，但主要目标都是在随机的局面下获得尽可能高的评分（「凹分」）；评分由五维属性分与所学技能分构成，因此凹分 = 尽可能高的五维属性与总技能点（以学习更多技能）。

## 1. 回合与流程

### 1.1 总回合数

- 标准育成共 **0–77 共 78 个回合**（0-based，游戏中显示为第 1–78 回合）；一部分剧本总回合数更少，由剧本单独设置。
- 回合按区间划分的**育成阶段**（出道赛前、URA、夏合宿等）见 [§2](#2-育成阶段特殊回合区间)，学年划分见 [§3](#3-年份)。

### 1.2 回合阶段

每个回合按以下阶段顺序推进，阶段内可由 Trainer 决策：

| 阶段 | 职责 | 可决策 |
|---|---|---|
| `Begin` | 回合开始事件（剧本事件、友人事件、抽签、结局等） | 事件选项 |
| `Distribute` | 人头分配到 5 个训练位、分配 Hint | 否 |
| `StoryShop` | 剧本商店 / 增益选择（**剧本预留阶段，当前无剧本使用**） | 剧本自定义 |
| `Train` | 选择主行动（训练 / 比赛 / 休息 / 外出 / 治病） | 是（主行动） |
| `AfterTrain` | 训练后追加事件（Hint、加练、友人点击等） | 事件选项 |
| `End` | 剧本回合结算（当前通用层无处理，供剧本 override） | 否 |

- 通用基座只显式处理 `Begin` / `Distribute` / `Train` / `AfterTrain`，其余阶段留空供剧本使用。
- 不同剧本可插入剧本专属阶段（如拉面选面 / 地区、温泉挖掘）。

### 1.3 主循环

```
run_stage(trainer) → while next() { run_stage(trainer) } → 育成结束处理
```

`next()` 推进阶段或回合；跨回合时检查**自选比赛是否达标**（不达标直接终止育成），见 [§6.4](#64-自选比赛达标)。

## 2. 育成阶段（特殊回合区间）

标准育成按回合区间划分为若干**阶段**，其中部分区间带特殊规则（动作受限、训练等级锁定等）。剧本可自定义专属阶段（如拉面的 RMJ 结算、温泉的汤浴会），本文只列**通用**阶段。

常规选项包括：训练（某种属性，或剧本特训）、比赛、休息、出行（普通 / 友人）；生病时还可选择治病。

| 阶段 | 回合区间 | 特征 | 判据 |
|---|---|---|---|
| 出道赛前 | 0–10 | 不可比赛，只能训练 / 休息 / 外出 / 事件 | `turn < 11` |
| 出道赛 | 11 | 固定比赛（唯一动作） | 生涯比赛表 |
| 常规育成 | 12–71 | 所有常规选项；生涯比赛回合 + 自选比赛 | 生涯比赛表 / `12 ≤ turn ≤ 71` |
| URA 回合 | 72–77 | 73 / 75 / 77 固定决赛（唯一动作）；**72 / 74 / 76 可训练、休息、普通外出，不可比赛** | 生涯比赛表 / URA 固定回合 |
| 夏合宿 | 36–39 / 60–63 | 训练等级锁 5、不可出行、休息强化、无随机事件 | 回合区间 |

### 2.1 生涯比赛回合

- 生涯比赛回合的常规动作**只有比赛**。
- 该回合**不进行人头分配、也不掷 Hint**（人头分布被清空）。
- 比赛加成结算见 [§6.3](#63-比赛加成)。

### 2.2 夏合宿

- 触发区间：turn **36–39** 与 **60–63**。
- 效果：
  - 所有训练等级强制为 **5**；夏合宿期间的训练**不计入基础训练等级**（基础等级计数规则见 [§5.1](#51-训练位与等级)）。
  - 动作菜单收窄：只允许训练、比赛、休息；**不允许**普通外出、友人出行、治病。
  - 休息固定获得 体力 +40、干劲 +1。
  - 部分剧本（如拉面）在夏合宿休息时同时自动治病，属剧本差异。

## 3. 年份

标准育成跨 **3 个学年**，每学年 24 回合；URA 回合（72–77）为最终阶段，通常并入第 3 年口径处理。

| 年份 | 回合区间 | 关键节点 |
|---|---|---|
| 第 1 年 | 0–23 | 出道赛（turn 11）、年末结算（turn 23） |
| 第 2 年 | 24–47 | 新年（turn 24）、夏合宿（36–39）、年末结算（turn 47） |
| 第 3 年 | 48–71 | 新年（turn 48）、夏合宿（60–63）、年末结算（turn 71） |
| URA | 72–77 | 固定决赛 + 训练，见 [§2](#2-育成阶段特殊回合区间) |

- **年边界**：turn **24 / 48 / 72** 为新年起点；剧本的年度结算多在年末回合（拉面 RMJ = turn 23/47/71），一部分剧本在年中（11、35、59）也有结算。
- **陷阱**：年度结算 / 地区选择的下标**不能用「当前年份 − 1」现推**——年边界在 turn 23/47/71，这些回合仍属上一年（如 turn 23 → 第 1 年），须按显式年份下标归档。

## 4. 开局与卡组

### 4.1 卡组

- 卡组固定 **6 张**（可由剧本配置）；其中通常含 1 张剧本友人 / 团队卡，其余为训练支援卡。
- 卡组允许携带多张友人 / 团队卡，但**只取最后一张**作为剧本友人。
- 卡的类型码：

| 类型码 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 含义 | 速度卡 | 耐力卡 | 力量卡 | 根性卡 | 智力卡 | 剧本友人 | 团队卡 |

- 开局会统计各类型卡的数量，供剧本固有 / 训练倾向使用。
- 卡的「突破等级」与卡 ID 一起编码（数据约定，见 [实现细节 §数据约定](game_implementation.md#3-数据约定)），突破等级决定卡面数值档位与初始羁绊。

### 4.2 开局初始化

- **初始属性提升**：每张卡的初始属性提升（初期◯◯アップ）拆成五维 + 技能点，开局直接累加到马娘身上。
- **初始比赛加成**：6 张卡的「赛后」（レースボーナス）词条累加为初始 `race_bonus`。
- **初始羁绊**：每张卡的初始羁绊取卡面值。
- **构造顺序铁律**：五维属性 = 马娘初始值 + 开局继承；五维上限 = **剧本基值上限 → 再累加开局继承上限**。任何剧本不得在构造后整体赋值五维上限（会擦掉继承增量）。

### 4.3 开局初值

| 项 | 初值 |
|---|---|
| 体力 / 体力上限 | 100 / 100 |
| 干劲 | 3（普通） |
| Hint 打折总级数 | 21（按全部初始技能 3 级打折） |
| 已学技能评分 | 510（马娘固有技能开局自动习得；客户端不单独下发该值） |

## 5. 训练

### 5.1 训练位与等级

- 5 个训练位：速 / 耐 / 力 / 根 / 智。
- **基础训练等级** = `floor(该训练累计成功次数 / 4) + 1`，范围 1–5；每**成功执行**一次该训练，计数 +1。
- 夏合宿期间显示等级恒为 5；夏合宿期间的训练**不增加**基础训练等级计数。
- 剧本事件 / 年末结算可批量提升训练等级（剧本机制）。

### 5.2 人头分配

每回合 `Distribute` 阶段重新分配人头到训练位：

1. **顺序**：理事长 → 记者 → 剧本友人 → 团队卡 → 支援卡 → NPC。
2. **出现判定**（先判「不在」）：
   - 基础不在权重：支援卡 **50**、友人 / 团队卡 **100**、理事长 / 记者**固定 200**、NPC **必定出现**。
   - 「出场率提升」= 降低不在权重（对支援卡 / 友人 / 团队卡生效，理事长 / 记者不受影响）。
   - 判定概率：`p = 不在权重 / (500 + 不在权重)`（分母为 5 个训练位的基础权重和）。
3. **训练位分配**：已判定出现的人头按权重分配到 5 个训练位，权重为 `[100,100,100,100,100]` + 得意率加权（得意训练位 `+= 得意率`）。
4. **约束**：通常每位置最多 5 人（部分剧本可更多）；同一人物不重复出现在同一位置（部分剧本允许「分身」出现在不同位置）；友人 / 团队卡 / 理事长 / 记者在任一位置至多出现一个（必定优先分散到不同位置）。
5. **可用门槛**：默认剧本友人 turn ≥ 2、记者 turn ≥ 13 才可能出现在训练；**每个剧本可不同**，由剧本逻辑决定。

### 5.3 Hint（灵感）分配与触发

分四步：**分配 → 选择 → 单次结算 → 上限**。

**⑴ 分配**
- 仅支援卡人头参与判定；剧本友人 / 理事长 / 记者 / NPC **不产生** Hint。
- 每张卡独立判定：`p = 基础 Hint 率 × (1 + 该卡 Hint 概率加成 / 100)`，命中则该人头本回合带叹号。
- 剧本可提升 Hint 出现率（剧本加成）。

**⑵ 触发选择**
- 默认：该训练位上所有带叹号的人头中，**随机选 1 个**触发。
- 变体「全部触发」：剧本开启后，该位上**所有**叹号都触发（全体支援启发）。
- 变体「次数增加」：带强制启发数加成的人头，其 Hint 事件触发 `1 + 加成` 次，每次**独立判定**。

**⑶ 单次结算**
- 先掷 Hint 属性概率（默认 25%）：
  - 命中 → **加属性**：按训练位对应的 Hint 属性值表加属性；
  - 未命中 → **加 Hint 等级**：增至该卡的总 Hint 等级。
- 两条分支都额外 **羁绊 +5**。
- Hint 等级增量：支援卡为 `1 + 卡面 Hint 等级`，**非支援卡恒为 1**。

**⑷ 上限**
- 每张支援卡 Hint 等级总量上限 **60**；单次增量还受 `min(5)` 与 `min(60 − 已有总量)` 截断。
- 额度用尽（增量 ≤ 0）时，该卡**一律改为加属性**，不再加技能。

### 5.4 训练值计算

```
// 基础值与体力（训练表按 [训练类型][等级] 取值）
basic   = 训练基础值[训练位][等级-1]        // [速,耐,力,根,智,PT,体力] 共 7 列
vital   = basic[6]                          // 通常为负值（消耗）；智训练为正值（回体）
status_pt[i] = basic[i] + 支援卡副属性加成[i]   // 仅当 basic[i] > 0 的维

// 乘区
real_value = status_pt[i]
  × (1 + 0.01 × 友情加成)                       // 仅闪彩时生效
  × (1 + 0.01 × basic_motivation × (1 + 0.01 × 干劲加成))
  × (1 + 0.01 × 训练效果加成)
  × (1 + 0.05 × 训练位人数)                     // 含 NPC 与分身，排除理事长 / 记者
  × (1 + 0.01 × 马娘成长率[i])
status_pt[i] = floor(real_value)

// 精力相关
basic_motivation = (干劲 - 3) × 10
```

- **体力消耗降低**：仅当该次体力增量为**负**（消耗）时，按 `vital × (1 − 体力消耗降低% / 100)` 结算。
- **智训练回体**：智训练的基础值本身含回体；若该训练位**有闪彩卡**，额外加「智训练体力恢复」词条值。不闪彩时只有基础回体。
- `basic_value` 为**训练基础值表**，由剧本提供。

### 5.5 友情训练（彩圈）

- 一张支援卡位于其**得意训练位**且**羁绊 ≥ 80** 时显示为**彩圈**。
- 团队卡：在其 Buff 生效期间所有位置都算闪彩；团队卡 Buff **由使用团队卡的剧本自行维护**。
- **只有闪彩的卡才贡献友情加成**；不闪彩时该卡的友情词条归零。
- 多张卡的友情加成**累乘**：`(100+a)(100+b)/100 − 100`。

### 5.6 训练失败率

训练失败率是**二次函数拟合**：

```
x0 = 训练体力阈值[训练位][等级-1]
f  = if 体力 < x0: (100 − 体力) × (x0 − 体力) / 40
     else: 0
f  = min(f, 99)
f  = f × (100 − 失败率下降) / 100 + bias     // bias：擅长训练 −2，不擅长训练 +2
f  = min(f, 100)
```

- 失败与**大失败**区分；大失败会追加「生病」与「不擅长训练」状态。
- 失败 / 大失败的具体数值与判定方式属模拟实现，见 [实现细节](game_implementation.md#4-模拟简化与真机差异)。

### 5.7 训练后的追加事件

训练成功后：

- 训练后按人头类型增加羁绊：支援卡 **+7**、理事长 / 记者 **+5**，上限 100（爱娇再全局 +2）。
- 随机选一个带 Hint 的人头，触发 **Hint 事件**（见 [§5.3](#53-hint灵感分配与触发)）。
- 非夏合宿时，按概率触发**加练事件**：理事长羁绊 +5，二选一——该训练属性 +5 且体力 −5，或体力 +5。
- 若点击了剧本友人：首次必定触发「友人登场」，之后**每次点击**都触发「点击友人」事件（无概率门槛）。
- 若点击了理事长 / 记者：触发对应的点击事件。

**羁绊来源汇总**（上限统一 100）：

| 来源 | 增量 |
|---|---|
| 训练后 | 支援卡 +7；理事长 / 记者 +5 |
| Hint 事件（属性 / 技能两条分支） | +5 |
| 支援卡连续事件 | +10 / +5 / +5（三段递减） |
| 理事长 / 记者点击事件 | +5 |
| 加练事件 | 理事长 +5 |
| 友人事件（登场 / 点击 / 出行 / 新年等） | +10（登场）/ +5（其余） |
| **爱娇**（全局修正） | 以上**所有**羁绊获取额外 **+2**（如训练后支援卡 +7 → +9） |

### 5.8 舍入与上下层数值

剧本会显示「上层」与「下层」数值：

- **下层数值**：基础公式算出的训练属性值，向下取整，基础上限 100。
- **总数值**：叠加剧本加成后算出的训练属性值，向下取整。
- **上层数值** = 总数值 − 下层数值，基础上限 100，上限可能被剧本提升。
- **最终训练数值** = 下层数值 + 上层数值。
- 属性超过 1200 的部分在实际游戏**显示时**再减半（见 [§9.4](#94-显示属性压缩)）。
- 上下层属**剧本通用机制**，但**各剧本的上层算法不同**。

## 6. 比赛

### 6.1 生涯比赛

- 生涯比赛回合由马娘数据的比赛表（turn 11–71）加上固定的 URA 决赛 turn 73/75/77 决定。
- 生涯比赛回合只返回「比赛」一个选项；本项目默认所有比赛胜利，不考虑失败（结果复盘时除外）。
- 比赛后触发生涯比赛系统事件，属性 / PT 效果乘以比赛加成。
- 未胜利赛等失败分支在本项目不模拟。

### 6.2 自选比赛

- 在通常训练和夏合宿回合也可以选择参加任意比赛（受剧本封锁规则影响）。
- 当前回合比赛的最高等级由比赛等级表按回合查得（1 = G1 最高 … 4 = OP/最低）。
- 实际游戏中能否比赛还受马娘的（距离、场地）适性影响；项目只做简单模拟。
- 自选比赛事件在游戏中是一个**可决策 + 结果分支**的选项（固定体力档或大成功 / 成功体力档）；具体数值属模拟数据，见 [实现细节](game_implementation.md#4-模拟简化与真机差异)。
- 可选回合区间由通用规则给定（约 turn 13–71），个别剧本的历史行为可能差一回合。

### 6.3 比赛加成

- 来源：支援卡的「赛后」词条累加（开局写入）。
- 作用：比赛事件的**属性 / PT** 效果乘以 `(100 + 比赛加成) / 100`，乘算后**四舍五入**；**不影响体力、干劲等其它字段**。
- 剧本可另有比赛末附加加成（剧本机制）。

### 6.4 自选比赛达标

- 每段自选比赛区间结束时（该区间的结束阶段或下一回合开始）检查各区间比赛场数是否达标。
- 不达标 → 育成失败（直接终止）并结算当前评分。

## 7. 休息与外出

### 7.1 休息

- 非夏合宿：按权重随机三档——寝不足（体力 +30）、正常（+50）、大成功（+70）；权重默认 18 / 57 / 25。
- 夏合宿：固定体力 +40、干劲 +1；部分剧本同时自动治病。

### 7.2 普通外出

- 随机触发三个普通外出事件之一。
- turn ≥ 24 且尚未抓过娃娃时，有概率触发抓娃娃事件（获得 Hint / 体力 / 干劲，并记录已抓过）。

### 7.3 友人出行

- 前置：友人已解锁、非 URA 回合、出行次数未用完。
- 共 **5 次**，依次触发 5 个友人出行事件；全部触发完后无法再使用友人出行。
- 每次出行消耗一个出行名额。

### 7.4 治病

- 仅在生病时可选。
- 效果：恢复体力并清除「生病」与「不擅长训练」状态。
- 实际游戏有多种状态异常，本项目只做简单模拟。

## 8. 事件

### 8.1 事件结构

事件包含：

| 字段 | 含义 |
|---|---|
| `id` | 事件 ID |
| `name` | 事件名 |
| `person_index` | 该事件关联的人头（用于羁绊归属；可选） |
| `trigger` | 触发类型：随机（限次数）/ 代码触发 / 固定回合 |
| `choices` | 选项组，每组内含多个选项（带概率与效果） |
| `player_select` | 是否需要玩家（Trainer）选择选项组 |

- 选项可带**结果标签**（普通 / 成功 / 大成功 / 失败 / 大失败），用于展示与分支表述。

### 8.2 事件流程

1. 若 `player_select` 为真：交给 Trainer 选择**选项组**。
2. 否则直接选第 0 组选项。
3. 选中后按组内概率加权随机决定具体分支并应用效果。

### 8.3 效果应用

- 效果值含：五维 + PT、体力、体力上限、干劲、Hint 等级、羁绊，以及状态增减。
- 状态增减**由游戏 / URA 侧下发**（本仓模拟端当前未应用，见 [实现细节](game_implementation.md#6-未实现--外部下发)）。
- 友人事件额外乘算「事件效果提高」（对属性 / PT）与「事件恢复量提高」（对正向体力）。
- 局中继承事件（turn 30 / 54）触发局中继承，见 [§10.1](#101-继承)。

### 8.4 支援卡事件

- 支援卡会触发「随机事件」与「连续事件」；项目模拟时只考虑**连续事件**。
- 连续事件段数：SR 通常 2 段、SSR 通常 3 段（有例外）；模拟使用固定事件 ID 与固定效果。
- 连续事件的**触发率与连续事件率可被剧本改写**（通用 seam）。
- 不在「无事件回合」列表中的回合才可能发生随机事件。

### 8.5 掉心情事件

- turn ≥ 12 才可能抽到。
- 效果：体力 −5、干劲 −1。
- 若持有心情盾，则改走「心情盾被消耗」分支：体力 −5、干劲不掉（消耗 1 层盾）。

## 9. 状态与属性

### 9.1 马娘属性

| 字段 | 含义 |
|---|---|
| 五维属性 | 速 / 耐 / 力 / 根 / 智，上限由剧本基值 + 继承决定 |
| 体力 / 体力上限 | 初始 100 / 100 |
| 干劲 | 1–5，初始 3 |
| 技能点 | 只增不减（本项目不模拟「点技能」消耗） |
| Hint 打折总级数 | 技能点折扣级数，初始 21 |
| 已学技能评分 | 开局 510（固有技能），本项目不随对局变化 |
| 比赛加成 | 见 [§6.3](#63-比赛加成) |
| 状态标识 | 切者 / 小切 / 爱娇 / 擅长 / 不擅长 / 心情盾 / 幸运体质 / 休息心得 / 抓过娃娃 / 生病 |
| 生涯比赛 / 比赛记录 | 比赛表与已比赛场次 |

- **属性与技能点有下限 0**（防御性规则，避免负值）。

### 9.2 状态标识

| 标识 | 效果 |
|---|---|
| 切者 | 技能消耗 PT −10%；**局内由游戏 / URA 下发**（模拟路径另有事件判定，见实现细节）；与小切互斥，切者优先 |
| 小切 | 技能消耗 PT −4%；**局外（育成前）获得** |
| 爱娇 | **所有**羁绊获取固定 **+2**（如训练后支援卡 +7 → +9）；**由游戏 / URA 下发**（模拟端当前仅在训练后一处接入） |
| 擅长 / 不擅长训练 | 训练失败率 ∓2%；由游戏 / URA 下发（模拟端待接入） |
| 心情盾 | 抵消一次干劲下降（见 [§9.3](#93-干劲机制)） |
| 幸运体质 | 实际游戏：抵消一次生病；本项目模拟暂不完善 |
| 休息心得 | 每回合开始时体力 +5，并逐步判定结束 |
| 抓过娃娃 | 普通外出抓娃娃的解锁标记 |
| 生病 | 解锁「治病」动作；以位集记录种类，数值效果见 §9.5 |

### 9.3 干劲机制

- 干劲范围 1–5，影响训练值：`basic_motivation = (干劲 − 3) × 10`。
- **心情盾**：掉干劲时优先消耗盾（一次扣减无论几级只消耗一层），盾为 0 才真掉；涨干劲不消耗盾。
- 干劲变化来源：

| 来源 | 变化 |
|---|---|
| 掉心情事件 | −1 |
| 训练失败 | −1 |
| 训练大失败 | −3 |
| 抽签 / 年末事件 | 视结果 −1 或 +1 ~ +2 |
| 出行（普通 / 友人） | +1 ~ +2 |
| 剧本 / 友人事件 | 视效果 |

- 干劲最终夹在 `[1, 5]`。

### 9.4 显示属性压缩

- 属性超过 1200 时，超过的部分**显示时**减半并向下取整；AI 按原始值存储和计算。
- 例：原始属性 1600，显示为 `1200 + floor((1600 − 1200) / 2) = 1400`。

### 9.5 生病（状态异常）

- 游戏中状态异常有多种、可同时存在；本项目以位集记录，**各状态的数值效果与消除条件尚未模拟**，
  当前只做「标记 + 解锁治病」的简化处理。
- 已知种类（讨论记录，尚未实测标定）：

| 种类 | 效果 | 消除 |
|---|---|---|
| 太り気味（变胖） | 训练的速度增量恒为 0 | 待补 |
| 肌あれ（皮肤差） | 随机掉干劲 | 待补 |
| 片頭痛（偏头痛） | 无法增加干劲、随机掉干劲 | 待补 |
| なまけ癖（摸鱼） | 选择训练后按概率跳过训练 | 待补 |
| 夜ふかし気味 | 待补 | 待补 |

- 練習ベタ（不擅长训练）在游戏中同属状态异常，但本项目由独立字段 `bad_trainer` 承接，
  与状态异常中的对应位同源（同置同清）。
- 协议缺口：通信层目前只下发「是否生病」的布尔值；要按种类区分，需原样透传游戏的
  `chara_effect_id_array`。

## 10. 继承与支援卡

### 10.1 继承

| 项目 | 公式 |
|---|---|
| 开局属性 | `蓝因子 × 7` |
| 开局上限 | `floor(蓝因子 × 5.33)`（估算；3 星蓝因子按截断后为 15） |
| 局中属性（turn 30 / 54） | `蓝因子 × 6 + round(剧本因子 × scale)` |
| 局中上限 | `floor(蓝因子 × 5.33)`（估算） |
| 局中 PT | `round(剧本因子[PT] × (0.5 + 0.5 × scale))` |

- `scale` 为一次 `random(0..2)` 抽样，**五维与 PT 共用同一次抽样**。
- 开局构造顺序见 [§4.2](#42-开局初始化)。

### 10.2 支援卡训练效果

支援卡的训练词条经汇总为训练效果，主要字段：

| 字段 | 含义 | 叠加方式 |
|---|---|---|
| 友情 | 友情加成 | 累乘：`(100+a)(100+b)/100 − 100` |
| 干劲 | 干劲加成 | 加算 |
| 训练 | 训练效果 | 加算 |
| 得意率 | 得意率 | 不叠加，单卡 |
| 副属性 | 副属性加成 | 加算（先加到基础值再进乘区） |
| 智训练体力恢复 | 智训练回体 | 加算（仅该位闪彩时生效） |
| 失败率下降 | 失败率下降 | 累乘补 |
| 体力消耗降低 | 体力消耗降低 | 累乘补 |
| 事件效果提高 | 友人卡词条 | 加算 |
| 事件恢复量提高 | 友人卡词条 | 加算 |
| 强制启发数 | 固有改变 Hint 次数 | 见 [§5.3](#53-hint灵感分配与触发) |

### 10.3 支援卡固有效果

- SSR 支援卡满足条件时触发固有效果，提高自身面板属性。
- 完整编号体系、映射与实现状态见 **[支援卡固有效果（unique_effect）](support_card_unique_effect.md)**。

## 11. 友人

绝大多数剧本都有一个专属的友人卡或团队卡（剧本友人）。未携带剧本友人卡时无法享受完整的剧本机制增益，因此模拟时通常只考虑携带剧本友人的情况。
友人卡不触发彩圈或 Hint 事件，且不出现在训练中的概率高于普通支援卡。

### 11.1 友人状态机

```
未点击 → 已点击未解锁 → 已解锁 → 离开
```

- 未点击：尚未点击过友人。
- 已点击未解锁：已点击友人，等待「友人解锁」事件。
- 已解锁：可选择「友人出行」。
- 友人开始出现在训练中的回合数根据剧本不同。

### 11.2 友人点击流程

1. 首次点击训练中的友人 → 触发「友人登场」事件。
2. 之后每次点击 → 触发「点击友人」事件（无概率门槛）。
3. 回合开始判定：未解锁状态下按概率触发「友人解锁」事件（羁绊 < 60 用低概率，否则用高概率）。
4. 解锁后才可选择友人出行（5 次）。

### 11.3 友人卡词条

- 「事件效果提高」：对友人事件的五维 + PT 乘算。
- 「事件恢复量提高」：对友人事件的**正向**体力乘算。

## 12. 评分

### 12.1 总分公式

```
score = 已学技能分 + PT 分 + Σ 五维属性分
```

### 12.2 各分量

| 分量 | 计算 |
|---|---|
| 已学技能分 | 初始 510（固有技能），本项目不随对局变化 |
| PT 分 | `floor(总 PT) × PT 折算率 × 折算系数`，其中 `总 PT = 技能点 + Hint 总级数 × Hint 折算率` |
| 五维属性分 | 按 `min(属性, 五维上限)` 查表 |

- 五维分表有档位上限，越界饱和到表末。

### 12.3 PT / Hint 折算系数

- 用以模拟实际游戏中「PT / 技能打折 Hint → 学技能 → 技能评分」的过程：先把 Hint 等级按 Hint 折算率换算成额外 PT，再把 PT 按 PT 折算率换算成技能评分。
- 切者：实际效果为「技能花费 PT −10%」，按 PT 折算率 ×1.1 模拟。
- 小切：实际效果为「技能花费 PT −4%」，按 PT 折算率 ×1.04 模拟。
- 两者互斥，切者优先。
- **只乘 PT 项**，不改变五维分与已学技能分。

### 12.4 评分分解

评分可分解为：已学技能分 + PT 分 + 五维分[5]，分量之和逐位等于总分，用于搜索层的终局归因。

## 13. 育成结束与结局

- 育成结束于回合 77。**所有结束相关事件统一在 turn 77 结束后（`AfterTrain` 或更晚）判定**，不在回合开始时提前触发。
- 结束事件链包含：
  - 剧本友人结束事件；
  - 通用结局事件（`ending`）；
  - 剧本专属结局事件（如拉面另有专属结局事件）。
- 事件链执行完后进入育成结束处理，由剧本给出结束奖励 / 收尾结算，再按 [§12](#12-评分) 计算终局评分。
- AI 侧取「育成结束 · 点技能前」的终局帧作为终局数据（客户端协议与记录口径见项目文档）。
