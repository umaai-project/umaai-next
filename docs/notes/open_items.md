## 近期收口（2026-10-24）

- **#29 训练后红点的默认实现口径（含 `hint_count_bonus`）**：已落地——`default_after_train` 的红点部分抽为 `BaseGame::do_hint` 可复用件（不占契约名，按 A13 形态）并吸收完整口径：`hint_count_bonus` 发生次数（`1 + bonus`）、等级双截断（`min(5)` 且 `max_hint_per_card − total_hints`）、`total_hints` 单卡累计、超限只给属性红点。发生率修正仍归剧本覆写 `distribute_hint`（A3 口径不变）；非卡人头按 1 级 1 次处理（不触卡组累计）。**默认行为不等价**：引擎三份基线已重录（`basic_full_run` 数值未变、`basic_search_root` / `basic_seed_sweep` 位移）；温泉仓训练路径随之位移并重录基线（固定种子 42：评分 70897 → 70717），其 bath 路径（超回复红点）仍走温泉仓自持 `do_hint`（含 `has_friendship` 语义）。
- **#30 `sample_bucket` 暴露为 pub 原语**：已落地——`umasim::game::sample_bucket`（经 `pub use traits::*` 亦可达 `game` 层）pub 化，等价改动、与 `WeightedIndex` 逐位一致不变；温泉仓 `event.rs` 的本地最小实现已删除并改用引擎件，固定种子基线在切换前后位移完全一致（隔离实证，逐位不变）。
- **#33 通用层「卡组卡种数」判断口径（含友人 / 团队卡）**：已按候选②落地（用户拍板）——`DeckSpec.min_types` 扩为**全卡组 7 类口径**（速 / 耐 / 力 / 根 / 智 + 友 5 / 团 6，必带卡经 `Composition::kinds_with` 计入判定），并新增通用原语 `deck::deck_kinds`（全卡组 7 类 distinct 计数，校验同 `deck_types`）与 `deck::fixed_card_types`（必带卡类型解析，去重）。带必带卡时 `compositions` 需触数据根、返回 `Result`；无必带卡时行为不变。**口径变化**：`--fixed 友人 --min-types N` 的门禁含义从「训练卡种 ≥N」变为「全卡组卡种 ≥N」（同参数构成数位移，如 fixed 友人 + `min-types 4`：21 → 81）；miko 门禁「编成 ≥5 种」可按 `min_types: 5` + 必带友人表达（21101 + 友 = 5 种）。**存疑（2026-10-24 用户批注）**：`compositions` 的 7 类并集门禁可能过设计——实际剧本友人 / 团队卡**有且仅有一张、且为剧本固定**（至少 miko 为 1 友人 + 5 普通训练卡；团队卡近期剧本未出现），卡组组合本体只考虑五类普通训练卡。miko 门禁口径确认后若需区分，按剧本具体化（改回五类口径或归剧本仓自校验，均属减法改动）。
