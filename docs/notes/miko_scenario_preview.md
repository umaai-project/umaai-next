## 2. 核心机制

### 2.1 演目 ↔ 训练

|---|---|
| 流鏑馬 | 速度 |
| 神旗争奪戦 | 耐力 |
| 納舞 | 力量 |

| 飛駆 | 智 |

### 2.2 演目担当

- **编成内担当**：由编成支援卡类型决定（**速卡自动当流鏑馬担当**）。
- **编成外担当（神駒，固定 5 人）**：各演目 1 名，速 / 耐 / 力 / 根 / 智 各 1 个，故不会出现 0 人：

| 演目 | 编成外担当（神駒） |
|---|---|
| 流鏑馬 | **ダイワスカーレット**（新衣装） |
| 神旗争奪戦 | **ノーリーズン** |
| 納舞 | **マヤノトップガン** |
| 大曳神輿 | **ユキノビジン** |
| 飛駆 | **ブラストワンピース** |

- 育成马娘是统括 5 人的**神司駒**（leader），与 5 名神駒一起参加駿大祭。
- **NPC person 数据结构需要区分担当归属**：5 个固定 NPC 分别对应 5 个演目。现有 `BasePerson` 带 `person_type` / `train_type` / `chara_id`，可先用 **`chara_id → 演目` 查找表**；若同一 chara 被复用或数据不足，再在剧本侧扩展 person 结构（§5）。
- 待确认：编成内若也带了同一角色的支援卡，是否与固定神駒形成同名双人头；非本演目担当出现在某训练时，是否为其自身演目加 gauge；重复角标是否叠加。

### 2.3 演目ゲージ与演目稽古

- 左侧 **5 条 gauge**（对应旧代码 `gauge`）；训练时**有对应人头就 +1 进度**，**友情训练 +2**。
- **友情 +2 的范围待确认**：仅「彩人物」+2，还是有彩圈就全部 +2。
- **休息 / 非目标比赛也会涨 gauge，最低保证 +1**；具体涨哪一条 / 是否全部待确认。
- **gauge 不会随回合自然减少**（不会过期）。
- gauge 满 → 对应训练变为 **演目稽古**；执行后该 **演目 Lv +1、gauge 清零**；Lv 越高效果越强。
- **Lv1 演目稽古已给全部五项属性 +10 以上并提升技能点获取量**；Junior / Classic / Senior 三档效果不同。
- **Lv8 后增幅效益很大**；**满级 10**（友人 SSR；R / 不带 6）。
- **可延期**：亮起后不必马上执行、不会过期；多个演目同时亮起时，选其中一个**不会让其他消失**；可等训练同时闪友情 / 多人参加时再执行。
- **合宿训练与演目稽古是同一 ID / 同一回事**，合宿不是第三种训练类型。
- **最终结算（Senior 10 月後半）之后仍可攒 gauge、执行演目稽古**，直到 URA 结束（§2.5）。
- 待确认：gauge 上限；彩圈是否加成；演目稽古是否吃卡 buff / 彩圈；与普通训练的消耗差异；休息 / 比赛涨 gauge 的归属规则。

### 2.4 教导（教え）与转生

**3 次「伝受」**（回合按 1 基计）：

| 次数 | 时机 | 可选教导 |
|---|---|---|
| 第 1 次 | **第 3 回合**（0 基 turn 2） | 5 种基础：**羁绊 / 得意 / 灵感 / 助力 / 体力**；每种对应一个演目 |
| 第 2 次 | **Junior 年末回合末尾**（第 1 次発表会之后；UI 显示为 Classic 1 月前半；约 0 基 turn 24 末） | 新增 **特化 / 研钻** |
| 第 3 次 | **Classic 年末回合末尾**（第 2 次発表会之后；UI 显示为 Senior 1 月前半；约 0 基 turn 48 末） | 新增 **协力 / 不屈 / 両道** |

- **词条安排**：每次伝受后把 5 个教导**各分配到一个演目**（拖拽操作）；**合宿前与進捗発表会时可重新调整**，其余时间约半年不能改。
- **获得的教导固定、不随机**（10 种名单固定）；第 2 / 3 次的新教导在**前一次進捗発表会之后、年末回合末尾的伝受**获得。
- **转生**：用**初始 5 种教导之一作为材料**，强化**新获得的教导**——被用作材料的初始教导变为其「转成效果」，新教导则同时持有自己的「教导效果」+ 该转成效果。**初始教导之间 / 新教导之间不能互相转生**；每个初始教导只能用一次；经典年 2 次、资深年 3 次；**组合一旦确定不能改**；最终 5 个教导都带转成效果。
- **演目 Lv 越高，教导效果越强**（例：不屈 Lv9 需体力 ≥5 才降失败率，Lv10 时体力无关、失败率 -100%）。

**教导效果表**（4Gamer / Famitsu / 中文表一致）：

| 分类 | 教导名称 | 基础教导效果 | 转成效果（被用作材料时转化） |
|---|---|---|---|
| 初始（第一年） | 羁绊之教导 | 编成支援卡羁绊量＋（不叠加）；演目稽古主属性获得量 UP | 演目稽古主属性获得量 UP；合宿中该演目担当的编成支援卡**额外 1 人**出现在训练中 |
| 初始（第一年） | 得意之教导 | 得意率 UP | 得意率 UP；演目稽古**友情加成 UP** |
| 初始（第一年） | 灵感之教导 | 灵感（Hint）发生率 UP | 灵感发生率 UP；演目稽古灵感事件获得的**技能灵感 +1** |
| 初始（第一年） | 助力之教导 | 非友情训练时训练效果 UP；演目稽古获得「助力之支」（3 次内训练效果 UP） | 非友情训练时训练效果 UP；演目稽古获得「**助力之支／恩宠**」（3 次内训练效果 UP） |
| 初始（第一年） | 体力之教导 | 体力消耗降低 | 演目稽古的体力消耗降低 |
| 经典级追加 | 特化之教导 | 主属性获得量 UP；**基础属性上限＋** | 无 |
| 经典级追加 | 研钻之教导 | 演目担当参加的训练中，特殊事件「**追加稽古**（对应属性 **+20** 且**加 gauge**）」发生率 UP | 无 |
| 资深级追加 | 协力之教导 | 友情加成 UP；演目担当的编成支援卡**额外随机出现 1 处训练** | 无 |
| 资深级追加 | 不屈之教导 | 根据剩余体力降低训练失败率 | 无 |
| 资深级追加 | 両道之教导 | 副属性获得量 UP；演目稽古的训练效果 UP | 无 |

- 追加 5 种（特化 / 研钻 / 协力 / 不屈 / 両道）**转成效果均为「无」**：只作为转生材料，不参与转生。
- **教导作用于「演目担当」**（含编成外神駒 / 编成外支援角色），不是全体人头；羁绊教导的「编成支援卡羁绊量」只对编成卡生效。
- **「追加稽古」特殊事件效果后续需要关注**：属性 +20 且加 gauge，触发率 / 加多少 gauge 待真机确认。
- 待确认：转成后新教导是否完整保留基础效果（图源写法不统一）；重新分配词条的具体窗口；演目 Lv 对教导加成的逐级数值。

### 2.5 進捗発表会

**剧本结算共 3 次**，每次检查**全部演目 Lv** 的硬指标：

| 次 | 时机 | 最低演目 Lv |
|---|---|---|
| 第 1 次 | Junior **12 月後半** | **≥ Lv3** |
| 第 2 次 | Classic **12 月後半** | **≥ Lv5** |
| 第 3 次（最终） | Senior **10 月後半**（约 turn 67/68） | **≥ Lv6** |

- 有一个不达标就可能拿不到「**大成功**」；大成功给**友情 bonus / 得意率 / hint 率 / 赛道 bonus**；只有「成功」时效果缩水。
- **结算之后获得新的教导**（第 2 / 3 次新增教导在对应年末回合末尾的伝受中获得，随后可执行转生）。
- **最终结算后剧本剧情结束**：之后仍可攒 gauge、进入演目稽古，继续完成 URA 回合直到 **turn 78**（0 基 0..77）。
- 体验版体感：Junior / Senior 门槛不算苛刻，Senior 基本均等训练即可达标。
- 待确认：Junior / Classic 结算与伝受的精确回合坐标（「年末回合末尾」与 0 基 turn 24 / 48 的对应）；未达标的具体惩罚；大成功 / 成功的数值。

### 2.6 合宿与组卡门禁

- **合宿共 3 次**（Junior / Classic / Senior 各 1 次）；第一年（Junior）即有夏合宿；第一次为 **7 月前半–8 月後半**。
- **夏合宿判定必须修改，不使用基础版（`BasicGame`）**：基础版「Junior 无合宿」的日程 / 判定不适用；合宿排程归剧本仓自持。
- **合宿期间若有目标比赛，合宿会延长**：**不产生额外回合**，而是把**后续正常回合改为合宿回合**；延长量**可能按目标赛场次**计（若一次合宿期间有多次生涯比赛，需真机确认）。
- **合宿时全部训练都变节目练习（演目稽古）**；Senior 10 月後半的午式駿大祭是本剧本最终结算，之后剧情结束但仍可攒 gauge / 演目稽古直到 URA。
- **合宿前没有体力回复事件**（与 トレセン軒編 不同）；「不回体」仅指此，不禁止休息 / 正常训练选择。
- **组卡门禁**：**第三年节目练习的部分 buff** 需要支援卡类型 **≥5 种**才能激活；速 3 这类 4 类型以下编成吃不到。推荐 **速2 / 耐1 / 力1 / 智1 / 友1**（21101 + 友人，恰为 5 种含友人）。
- 待确认：Classic / Senior 合宿的具体回合；延长量是否按目标赛场次；「5 种」的计数是否含友人。

**现有数据核对（`umaDB.json`，2026-10-25）**：按引擎口径取基础合宿窗口 **Junior 12–15 / Classic 36–39 / Senior 60–63**（与 `BasicGame::is_xiahesu` 的 36–39 / 60–63 同口径）：

- **基础 4 回合窗口内，没有任何马娘有 ≥2 场生涯比赛**；Junior 窗口甚至 **0 场**生涯比赛。
- **只延长 1 回合时**：樱花进王（60→64）、凯斯奇迹 / 信念（39→40）会把第 2 场生涯赛纳入合宿。
- **若按场次链式累加**：樱花进王（60, 64, 65）、凯斯奇迹 / 信念（39, 40, 41）会出现一场合宿 **3 场生涯赛**。
- **凯斯奇迹特例（用户口径）**：游戏内是三连战（39 / 40 / 41），且第 3 战会触发**必须休息的事件**（史实梗）——正好用于验证「合宿延长 × 比赛回合 × 强制休息事件」三者叠加。
- → 「按场次 vs 固定 1 回合」可用上述马娘在真机验证；Junior 合宿在当前数据下不会触发延长。

### 2.7 友人「吾妻」

| 友人 | 演目 Lv 上限 | 出行效果 | 其他效果 |
|---|---|---|---|
| SSR（吾妻） | **10** | **各お出かけで（最低）演目 Lv +1** | **4 人以下的演目稽古に登場** |
| R | **6** | **各お出かけで（最低）演目 Lv +1** | **4 人以下的演目稽古に登場** |
| 不携带 | **6** | — | — |

- **等级上限由友人稀有度决定**（SSR 10 / R 6 / 不带 6），不是各演目担当卡稀有度。
- **Lv8 后增幅效益很大**，只有 SSR 能到 10；**0 凸即可，突破数不影响** → SSR 基本必需。
- **出行效果**：**当前最低演目 +1 Lv**（用户口述 + gamewith / kamigame + Famitsu 正文一致；中文表「各节目等级 +1」按表述差异处理）。
- **其他效果**：友人在**4 人以下（即不足 5 人）的演目稽古**位置补位出现；**是否在多个 <5 位置分身出现待确认**（默认按「单次补位」理解）。
- **疲劳恢复（初报，待确认）**：解锁出行时获得「疲劳恢复」flag，体力 ≤49 时 +15；触发次数 / 持续时间未在后续信息复述。

- **支援卡 6 张**：与引擎现有假设一致 → [`docs/issues.md`](../issues.md) 里「卡数 > 6 / ≤4」的处置条件**未触发**，[`open_items.md`](open_items.md) #25「引擎侧卡组长度下限」本轮仍不处置。
- **组卡门禁（≥5 种）**：属剧本档组卡约束（P8b′ 归剧本仓，见 [`open_items.md`](open_items.md) #22）；通用层 `DeckSpec.min_types: 5` + 必带友人可表达（21101 + 友 = 5 种），另有 `deck::deck_kinds` 供校验。门禁已确认是**第三年节目练习部分 buff** 的触发条件；「5 种」是否含友人仍待确认。
- **友人「吾妻」**：引擎只提供通用友人位（`PersonType::ScenarioCard` / `FriendState` / 出行段状态）；**`FriendCardState` 已区分 Empty / SSR / R**，可直接映射演目 Lv 上限 6 / 10 / 6。「只支持某张友人卡」、**4 人以下演目稽古补位**按剧本侧策略 / 人头布局实现，引擎不硬编码。**引擎已支持同人头多地占位**（负数占位，温泉秘汤分身为先例）；若真机确认友人分身，剧本侧对同一 `person_index` 再调 `distribute_person` 即可，约束仍是每训练位 ≤5 人、同训练位不重复、每训练位至多一个友人。
- **编成外 NPC 担当（神駒，固定 5 人）**：ダイワスカレー→流鏑馬、ノーリーズン→神旗争奪戦、マヤノトップガン→納舞、ユキノビジン→大曳神輿、ブラストワンピース→飛駆；`BasePerson` 现有 `person_type` / `train_type` / `chara_id` 但不直接带演目归属 → 剧本侧用 **`chara_id → 演目` 查找表**或扩展 person 结构（设计决策：`PersonType` 子变体 vs 查找表）。
- **夏合宿判定 / 延长**：**不吃 `BasicGame` 的合宿逻辑**（第一年即有），日程归剧本仓自持；**目标赛延长不增回合、把后续正常回合改标为合宿回合**（可能按场次），属排程数据，引擎零改。
- **合宿训练 = 演目稽古同 ID**：合宿不是独立训练类型，只需在合宿回合把训练位切到演目稽古；引擎无需新增类型。
- **剧本结束 ≠ 育成结束**：Senior 10 月後半最终结算后剧情结束，但育成继续到 **turn 78**；引擎按整局回合推进，剧本侧在结算后停止剧本 UI / 事件、保留 gauge 与演目稽古动作即可。
- **休息 / 比赛涨 gauge**：属剧本侧 gauge 更新规则（最低保证 +1），引擎零改；需在动作结算后统一入账。
- **属性上限（2200 / 1850 / 1800 / 1700 / 1800，绝对 2500）**：引擎不硬编码 1200——上限来自协议 `fiveStatusLimit` → `Uma.five_status_limit`（当前夹具 `[1200; 5]`）。**特化教导「基础属性上限＋」会在一局中途抬升上限**：该字段是 pub、`add_value` 按其夹取，剧本侧自行上调即可。
- **演目 Lv / 训练类型 id**：`TrainingBasicTable` 是动态等级行数，Lv 10 可用多行表表达；演目稽古换 id 后，默认 buff 计算与 `train_level_count` 仍按五训练口径，需剧本侧覆写。
- **演目担当 / gauge / 演目 Lv**：属剧本私有状态（5 个演目各存担当列表、gauge、Lv）；彩圈判定可复用 / 覆写 `Game::is_shining_at`；演目稽古是训练值 / 消耗 / hint / 友情的覆写点。
- **gauge 可延期 / 多亮并存**：剧本局面存「每演目 ready 标志」而非亮起即消费；由剧本在训练阶段决定何时兑现，引擎零改。
- **教导 buff**：得意率走 `Game::deyilv`、羁绊走 `BaseGame::add_friendship`、面板 / hint 经训练值覆写与 `distribute_hint` 覆写；年度 / 合宿前调整词条属剧本私有选择点；转生组合固定，引擎零改。
- **数据表**：剧本数据不进本仓（`gamedata/` 只读输入）；11 张表的 schema 归独立剧本仓，引擎不新增类型。
- **剧本仓形态**：按 [`docs/scenario/README.md`](../scenario/README.md) 建独立仓（crate 名 `umaai-miko`？待定），遵守「接入新剧本时引擎 `git diff` 为空」纪律。
